# React-tutorial

React 19 Create React App learning project using Font Awesome. This repository documents a learning exercise rather than a deployed product.

## Run locally

Install Node.js and npm, then:

```bash
npm install
npm start
```

The development server typically opens at http://localhost:3000.

## Available commands

- `npm start`: run the development server
- `npm run build`: build for production
- `npm test`: start the configured test runner

## Scope

This is a learning/experimental project. External service integrations may need configuration. No live production functionality is guaranteed by this README.
